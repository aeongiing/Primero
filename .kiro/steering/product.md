# 파라파라 (ParaPara) — 제품

빈티지·중고 의류 판매자를 위한 **멀티 플랫폼 업로드 자동화** 웹서비스.

## 한 줄 정의
파라파라에 상품을 한 번 등록하면 → 번개장터·fruits·차란·당근에 자동 등록·동기화한다.

## 절대 원칙 (의사결정 시 최우선)
- **SSOT**: 파라파라의 `표준_상품(Canonical Product)`이 유일한 원본이다. 모든 플랫폼 등록물은 이로부터 복제된다. 상태 변화(가격·판매·내림)는 항상 표준_상품을 기준으로 전파한다.
- **부분 실패 격리**: 한 플랫폼의 실패가 다른 플랫폼 작업을 막지 않는다. 실패는 사유와 함께 기록·재시도한다.
- **비밀 정보 비노출**: API 키·자격증명은 환경변수/시크릿에서만 로드한다. 소스·로그·오류 메시지에 평문으로 넣지 않는다.

## 핵심 플로우
업로드 → AI 분석(카테고리·색상)·설명 생성 → 사진 정렬/썸네일 보정 → 표준_상품 저장 → 플랫폼 매핑 → OpenClaw 발행 → 판매 동기화/미판매 할인.

## MVP 우선순위
- 높음: 업로드·정렬·AI 설명·보정·컨디션·매핑·OpenClaw 발행·판매 동기화·7일 10% 할인
- 낮음/추후: 모델명 찾기(정확도 검증 필요), Google OAuth, ebay 연동
