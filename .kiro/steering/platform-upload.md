# 플랫폼 업로드 지식 (High-Signal)

AI는 한국 중고거래 플랫폼의 입력 양식을 잘 모른다. 매핑·자동화 코드를 다룰 때 아래를 기준으로 삼고, 최신/상세 정보는 `platform-docs` MCP(`fetch`)로 각 플랫폼 도움말을 조회한다.

## 플랫폼 필드/카테고리 원본
- 각 플랫폼의 필수 필드·카테고리 트리는 `#[[file:.kiro/steering/플랫폼 input.md]]`가 단일 출처다. 추측하지 말고 이 문서를 따른다.
- 정규(canonical) 값 집합은 **차란** 기준을 채택하고 다른 플랫폼으로 축약·매핑한다.

## 플랫폼별 핵심 차이
- **번개장터**: 사진·상품명·카테고리·설명·가격 필수. 컨디션 등급 필드 **없음** → 컨디션은 설명 본문에 포함. 계절/소재 미지원.
- **차란**: 가장 표현력 큼. 브랜드·사이즈(S/M/L)·컨디션 등급(Excellent/Great/Very-good/Good)·핏·색상·계절(최대 4)·패턴·소재(최대 4)·스타일까지.
- **당근**: 제목·카테고리(여성의류/남성패션·잡화)·사이즈(문자열)·설명·가격·거래희망장소. 컨디션 등급 없음.
- **fruits**: 상세페이지 UI 벤치마킹 대상(좌측 이미지 갤러리 + 우측 정보 패널).
- **ebay(추후)**: Pre-owned 등급 체계, 빈티지 카테고리 트리.

## 매핑 규칙 (엄수)
- 컨디션 점수(0~10) → 플랫폼 등급: 9.0~10.0=Excellent, 8.0~8.9=Great, 6.5~7.9=Very-good, 0.0~6.4=Good.
- **최대 선택 개수 제약**: 차란 계절·소재 최대 4개. 대표성 우선순위로 정렬 후 절단.
- 허용 목록에 매핑 안 되는 값 → `unmapped_fields`에 전부 담아 수동 선택 요청.
- 매핑 후에도 비는 필수 필드 → `missing_required` **항상 반환** + 등록 보류.

## platform-docs MCP 사용 시점
- 플랫폼 카테고리/등급/필드의 최신 명칭이 불확실할 때 `fetch`로 해당 플랫폼 고객센터·정책 페이지를 조회해 확인한다.
- 조회 결과는 추측 대신 근거로만 사용하고, 확정 매핑은 `플랫폼 input.md`와 정합되게 유지한다.
